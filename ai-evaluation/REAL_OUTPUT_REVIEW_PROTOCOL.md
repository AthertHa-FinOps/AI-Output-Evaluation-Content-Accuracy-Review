# Recording evaluations of actual model outputs

**Status:** Procedure and empty log template only. No model responses or personal ratings are recorded here.

For independent evidence beyond the fictional practice cases, evaluate a small number of **real responses generated by a named model**, using inputs you are permitted to share. Do not reuse confidential employer tests, real customer documents or proprietary evaluation tasks.

## Capture the evidence

1. Prepare a fictional or public-domain source. Save its text, citation and version where relevant; note any permitted external lookup.
2. Write the task instruction and, if comparing responses, the same prompt and source for both models. Include language direction and any format rules.
3. Run the prompt in a model you can lawfully use. Record provider, exact model/version shown, date, settings if available, prompt and **unedited output**. Do not infer a model/version you cannot observe.
4. Before seeing any outside evaluation, read the output and record your first ACCEPT/REJECT rating or A/B preference, applicable rubric dimensions, source evidence and a concise rationale.
5. For Spanish tasks, record whether the source and output use English or Spanish and note regional wording and register where relevant. Include your own Spanish-language rationale for at least two genuinely completed reviews.
6. Verify any factual claim against the permitted source. If missing, record "not established" rather than making a confident inference.
7. Later, perform a separate reconsideration or independent reviewer comparison if actually available. Keep the first decision, second view and reason for changes distinct.
8. Publish only data you own and have permission to share, with identifying information removed and source permissions respected.

## Log format

The [empty review log CSV](model_output_log_template.csv) contains column headings, not filled examples. For each genuine run, store:

- Task ID; run date/time and timezone; source citation or fictional-data note
- Prompt and source artifact path; output language; model provider and version; saved raw-response path
- First decision and applicable dimension ratings; exact supporting evidence; original rationale and its language
- Follow-up review, if completed; reviewer identity/role if applicable; disagreement and final disposition
- Publication permissions and limitations

**Metrics:** Do not report agreement, accuracy, throughput, model win rate or completion percentage without real comparable observations and defined denominators. One person agreeing with an AI-written reference key is not an independent inter-rater reliability measurement.

## First eight runs: suggested mix (not completed)

Use one or two examples each of source-grounded factuality, instructions/format, cautious uncertainty and English–Spanish meaning. Add a pairwise near-tie. Record both successful and unsuccessful outputs as actually observed; do not select only easy failures.
