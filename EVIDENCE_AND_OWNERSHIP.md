# Evidence, ownership and project limits

The portfolio combines paid experience in transaction documentation with self-directed AI-output examples and a runnable reconciliation exercise. These are different types of evidence.

| Evidence type | What is available | What it supports |
|---|---|---|
| Paid experience | Real estate agreements, amendments, identity and financial supporting records, discrepancy follow-up and deadlines | Practical document checking and coordination in regulated transactions |
| Reproducible exercise | Python reconciliation of two fictional 14-row extracts, six unit tests and an exception register | A repeatable example of matching, exception reporting and conservative review rules |
| AI-drafted practice material | Thirty evaluation cases, ten response pairs, draft acceptability labels, reference scores and suggested actions | A structured exercise for discussing evaluation decisions; not independently scored work |
| Earlier review narrative | [Document-review notes](case-studies/detailed-evaluation-notes.md) on the AWS portfolio | An account of issues found and corrected; the underlying historical versions are not all linked |
| Personal review record | [Owner-review worksheet](ai-evaluation/OWNER_REVIEW_WORKSHEET.md) | Blank at this revision; no completed independent judgments are claimed |

## How the records are treated

The fictional source data is retained for comparison. A conflicting amount is flagged, not automatically overwritten. Two rows with matching contact information are not automatically assumed to be one record. Where the source does not show a completed test, the reference answer must not claim success.

AI assistance was used to draft cases, comparisons, code and documentation. The casebook now distinguishes the response assessment (16 ACCEPT, 14 REJECT) from an older mixed reference label (12 ACCEPT, 14 REJECT, 4 INSUFFICIENT_EVIDENCE). Four cautious outputs correctly avoid asserting an unverified business fact. All labels and rationales are AI-assisted, and automated checks do not certify personal evaluation performance.

## Work still to be demonstrated
